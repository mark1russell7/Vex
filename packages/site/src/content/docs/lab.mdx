The Lab builds a chain from chips. Each chip adds one call. The chips of the ops come from the domain of the current value: after `length()`, the Lab shows the ops of numbers.

The Lab shows the code of the chain, the result at each origin and the trace. The last panel shows the program as JSON. A Vex program is data: change the JSON, leave the field, and the Lab evaluates the new program.
