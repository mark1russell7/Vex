## How the site is made

The site uses Astro and Starlight. The widgets are React islands, and each widget runs the real `@vex/core`, `@vex/domains` and `@vex/testkit` packages in your browser. The reference tables come from the code at the time of the build.

GitHub Actions builds the site on each push to `main`. Before the build, the workflow runs the tests and writes a report. The specification page reads the report and shows the status of the tests of each requirement. Smoke tests open each page in Chromium, and a console error makes CI fail.

The source is on GitHub: [github.com/mark1russell7/Vex](https://github.com/mark1russell7/Vex).

## Writing style

The prose of this site follows ASD-STE100 Simplified Technical English (STE). STE is a style target. ASD does not certify this site. The linter [`ste-lint`](https://github.com/mark1russell7/ste-lint) checks the text in CI.

## Disclosure

An AI model (Claude, from Anthropic) wrote most of the text and the code of this repository, under the direction of the author. The STEMG of ASD-STE100 asks for this disclosure in its white paper on STE and artificial intelligence (June 2026).
