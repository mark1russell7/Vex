Write a Vex chain, or start from a preset. The Lab reads the chain as you type, evaluates it at each record of the space, and draws the result at each record. Select a record to see the trace of the evaluation there.

<Lab client:load />

## How the Lab works

- **Four spaces.** The boxes are a record space. Life is a grid space. The organization chart is a tree space. The rows are an array space. Each space has its own moves and axes.
- **A safe reader.** The Lab does not run your text as JavaScript. A small reader reads the chain: `const` lines, calls, arrow functions and literals. It permits only the members of the builder, so a shared link cannot run other code.
- **The ops of the current value.** Under the editor, the chips show the ops of the domain of the result at the origin. A chip adds the op to the end of the chain. After an axis, the chips show the reductions of the list.
- **A link for each program.** "Copy link" puts the space and the code in the address of the page. The link opens the same program.
- **Programs are data.** The last panel shows the program as JSON: the same tree that `serialize` gives.

The boxes are the same four boxes as the other pages. Drag a box in the Lab, and the results change.
